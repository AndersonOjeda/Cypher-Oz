# Frontend TTI

Next.js + TypeScript + Tailwind. Sprint 1: Home, registro, login, cuenta y WhatsApp.

Consulta [README del monorepo](../README.md) para instalar, ejecutar, configurar y probar el sistema completo.

Comandos: `npm ci`, `npm run dev`, `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`, `npm run test:e2e`.

Las pruebas E2E necesitan PostgreSQL local y el entorno virtual del backend; levantan servicios aislados en 3001/8001.
